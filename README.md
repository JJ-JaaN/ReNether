# new-ng

Privatni razvojni projekt za migraciju NetherGames BedWars na moderni Axolotl-PM (Bedrock 26.50), bez Dockera.

**Status: u izradi, nije produkcijski kompatibilan.** Repozitorij ostaje privatan; taj status ne ukida obveze iz licenci izvornog koda.

Pokretanje će se izvoditi s `./start.sh` nakon dovršetka početnog postavljanja i provjere kompatibilnosti. Originalni autori i licence bit će navedeni u `ATTRIBUTION.md`.

Izvori: [Axolotl-PM](https://github.com/axolotl-pm/PocketMine-MP), [NetherGames plugins](https://github.com/NetherGamesMC/plugins) i [NetherGames assets](https://github.com/NetherGamesMC/assets).
